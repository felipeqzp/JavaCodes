# JavaCodes
Repositório para os códigos em Java que foram desenvolvidos durante a disciplina de Programação Orientada à Objetos na faculdade de Ciência da Computação (4° semestre)

São códigos simples, nada tão aprofundado sobre Java, apenas o básico sobre POO, na disciplina vimos os principais conceitos e pilares, alguns tipos de diagramas, onde, construímos alguns também, e por último vimos o conceito de SOLID.

Como projeto final da disciplina tivemos que construir um sistema aplicando tudo o que aprendemos durante as aulas, desde o planejamento do sistema com os diagramas até a entrega final do código.
